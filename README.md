## 💻 How to Run Locally

### Option 1: Direct File Open (Zero setup required)
Simply double-click `index.html` in your file explorer to open it in Google Chrome, Microsoft Edge, or any modern browser.

### Option 2: Using Python Simple HTTP Server
Open your terminal in this directory and run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Free 1-Click Deployment Options

### Method 1: GitHub Pages (Recommended)
1. Create a new repository on your GitHub account ([github.com/NaravaAswini](https://github.com/NaravaAswini)) named `portfolio` or `NaravaAswini.github.io`.
2. Push the files in this folder to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/NaravaAswini/portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings > Pages > Branch: main > Save**.
4. Your website will be live at: `https://NaravaAswini.github.io/portfolio/`!

### Method 2: Vercel or Netlify
1. Go to [netlify.com](https://www.netlify.com/) or [vercel.com](https://vercel.com/).
2. Drag and drop the `narava-aswini-portfolio` folder into the Netlify Drop zone.
3. Your site will instantly go live with a custom URL and free SSL!
